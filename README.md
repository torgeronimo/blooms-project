# 🌸 Blooms Website

Welcome to the Blooms project! This app is a **pixel-perfect Figma conversion** into a modern React + TypeScript + Vite website. The goal was to take the design from Figma and recreate it faithfully as a polished, responsive web experience.

## ✨ What this project includes

- React + TypeScript frontend
- Vite-powered development and build workflow
- Tailwind-style utility classes and custom CSS
- Responsive gallery + carousel UI
- Mobile-friendly navigation
- Visual layout matching the Figma design, including spacing, rounded cards, and typography

## 🖼️ Design inspiration
This website was built based on a Figma design file and converted into a **pixel-perfect copy** of the visual layout. Every detail was considered to preserve the original design intent.

https://www.figma.com/files/team/983726173818896960/resources/community/file/1497437463361122374?fuid=983726168201870646

## 🚀 Getting started

```bash
npm install
npm run dev
```

Then open the local server URL that Vite prints in the terminal.

## 🧩 Project structure

- `src/` — application source code
- `src/pages/` — page components like Home, Gallery, About, Contact
- `src/components/` — reusable UI components and layout pieces
- `src/styles.css` — global styles and custom variables
- `vite.config.ts` — Vite configuration

## 💡 Notes

- The gallery is built as a responsive grid
- The carousel is designed to show centered cards with a clean look
- Navigation includes desktop and mobile menu states

## ❤️ Why this project is special

This isn’t just a starter template — it is a **real design conversion**. The site was built to match a high-fidelity Figma layout, making it a beautiful example of how design and code can come together.
